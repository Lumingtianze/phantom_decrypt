# PhantomCipher CLI Decryptor

[English](./README.md) | [简体中文](./README_zh.md) | [日本語](./README_jp.md)

A decryption tool for [PhantomCipher](https://github.com/Lumingtianze/obsidian-phantom-cipher).

## 🚀 Usage
1. Download the binary corresponding to your system architecture from the [Releases](https://github.com/Lumingtianze/phantom-decrypt/releases) page.
2. Place the executable in your Obsidian vault root (or any directory containing encrypted files).
3. Run the tool via terminal:
   ```bash
   ./phantom_decrypt
   ```
4. Enter your master password when prompted. The tool will automatically scan all files in the current directory and its subdirectories, then decrypt them in place.
