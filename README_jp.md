# PhantomCipher CLI 復号ツール

[English](./README.md) | [简体中文](./README_zh.md) | [日本語](./README_jp.md)

[PhantomCipher](https://github.com/Lumingtianze/obsidian-phantom-cipher) プラグインの復号ツールです。

## 🚀 使い方
1. [Releases](https://github.com/Lumingtianze/phantom-decrypt/releases) ページから、お使いのシステムアーキテクチャに対応するバイナリをダウンロードします。
2. 実行ファイルを Obsidian 保管庫のルートディレクトリ（または暗号化されたファイルが含まれるディレクトリ）に配置します。
3. ターミナルでツールを実行します：
   ```bash
   ./phantom_decrypt
   ```
4. プロンプトが表示されたら、マスターパスワードを入力してください。ツールは現在のディレクトリおよびサブディレクトリ内のすべての暗号化ファイルを自動的にスキャンし、その場で復号して元に戻します。
