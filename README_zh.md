# PhantomCipher CLI 解密工具

[English](./README.md) | [简体中文](./README_zh.md) | [日本語](./README_jp.md)

为 [PhantomCipher](https://github.com/Lumingtianze/obsidian-phantom-cipher) 插件开发的解密工具。

## 🚀 使用方法
1. 从 [Releases](https://github.com/Lumingtianze/phantom-decrypt/releases) 页面下载对应您系统架构的二进制文件。
2. 将可执行文件放置在您的 Obsidian 库根目录（或任何包含加密文件的目录）下。
3. 在终端中运行该工具：
   ```bash
   ./phantom_decrypt
   ```
4. 根据提示输入您的主密码。工具将自动扫描当前目录及其子目录下的所有加密文件，并进行原地解密还原。
